🎵 Govee LED Music Sync

A Python system that drives Govee LED strips in real time from audio, using an unofficial UDP protocol for instant, per-segment colour control. Includes a standalone light show player with automatic scene transitions.

🐍 Python 🌐 UDP Networking 🎧 Audio Processing 💡 Real-time Control

Project Overview

Govee's own music mode is limited and not very responsive. I wanted lights that react to music instantly and that I fully control, so I built my own sync system in Python.

How It Works

  • Direct device control: Communicates with the LED strip over an unofficial "razer" UDP protocol on port 4003, bypassing the slower official control paths.
  • Per-segment colour: Updates 50 addressable segments individually, so effects can move across the strip instead of changing it all at once.
  • Audio-reactive presets: Multiple presets that map live audio to colour and movement patterns.
  • Standalone light show player: Detects audio and switches between scenes automatically, so it runs without manual input.
