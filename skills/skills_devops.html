🛠️ DevOps & Tools

How I get code from my laptop onto a server and keep it running. At TasteLab I handled the full deployment myself: building images, publishing them, and running the services on a shared university server.

🐳 Docker 🧭 Portainer 📦 GHCR 🌿 Git

🐳 Docker

Containerized the entire TasteLab pipeline, including the Dagster services, MinIO storage, transcription and summarization components, and the Django dashboard, and deployed it as Docker stacks on a BUas server.

I first learned containerization in the Deploying ML Solutions block, where I built ML pipelines with Docker and cloud infrastructure.

See Deploying ML Solutions →

🧭 Portainer

Managed the TasteLab services on the university server through Portainer stacks, which made it possible to deploy, update, and monitor the containers without doing everything by hand on the command line.

📦 GHCR (GitHub Container Registry)

Published the TasteLab Docker images to GitHub Container Registry under the BUas ADSAI organization, so the server could pull new versions directly instead of building images on the server itself.

🌿 Git

Used for version control across all my projects, including the TasteLab codebase and this portfolio, which is hosted on GitHub Pages.
