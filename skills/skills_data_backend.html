Skill Category 5 skills

Data & Backend

The tools I use to move, store, and serve data. Almost everything here comes from building one real system: the TasteLab pipeline, which researchers used to process their experiment recordings.

Dagster FastAPI Django PostgreSQL MinIO

Dagster

The orchestration layer of the TasteLab pipeline. I used Dagster to define each processing stage as an asset with clear dependencies, from ingesting recordings through transcription and summarization to storing the results.

The pipeline grew step by step: it started as basic transcription scripts and became a full Dagster pipeline deployed on a university server.

FastAPI

Used at TasteLab to build API services within the pipeline's backend.

Django

Built the Django dashboard for TasteLab researchers, giving them a way to view and work with pipeline results without touching the underlying infrastructure.

PostgreSQL

The relational store in the TasteLab pipeline, holding structured metadata and processing outputs, while MinIO handled the large binary files. Also used SQL databases in my Machine Learning coursework.

MinIO

S3-compatible object storage for all video, audio, and processed artifacts at TasteLab. I integrated it as the pipeline's storage layer and deployed it as part of the Docker stack on the university server.

In Short

  • Designed and built a complete data pipeline, not just individual scripts
  • Chose the right storage for each kind of data: relational for metadata, object storage for media
  • Built both the processing backend and the interface researchers used
